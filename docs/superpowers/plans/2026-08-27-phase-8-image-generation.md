# Phase 8 Image Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver persistent OpenAI-compatible `POST /v1/images/generations` over authenticated ChatGPT Web with URL/Base64 output.

**Architecture:** Keep Images execution outside Conversation Engine. A dedicated image driver owns target Assistant image detection/fetch; an image service owns Page Pool lease, storage, hashing and GeneratedImageRepository; API routes own validation/encoding.

**Tech Stack:** Node 24, TypeScript, Fastify, TypeBox/Ajv, Playwright Chromium, node:sqlite, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-27-phase-8-image-generation-design.md`

## Global Constraints

- Only `n=1`.
- No partial image streaming or edits.
- Never expose ChatGPT temporary image URLs as persistent API output.
- Generated bytes live under `${DATA_DIR}/generated` and are signature-sniffed before persistence.
- No intermediate test execution in this implementation session per user instruction; tests are authored first and run only after all remaining V1 functionality is implemented.
- No new database migration.
